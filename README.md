A dynamic analytical dashboard utility designed to monitor campaign auditing, transaction velocity, and donor statistics for the Ataa Charity platform.

---

## 🚀 Key Features

* **📈 Analytical Charts**: Dynamic graphs displaying donation progress and volume details.
* **🔍 Audit Logs**: Direct view of AI campaign evaluations and status changes.
* **📊 Admin Control**: Advanced search filters to audit charity requests.

---

## 🛠️ Technology Stack

| Technology | Purpose |
| :--- | :--- |
| Node.js | Asynchronous JS runtime |
| Express.js | Lightweight web routing |
| MongoDB | Document aggregation pipelines |

## 🚀 Getting Started

### Prerequisites
- Node.js >= 18 (If applicable for package environment)
- Modern Web Browser

### Setup & Launch
1. Clone the repository:
   ```bash
   git clone https://github.com/YourOwner/Ataa-Charity-Platform-API-Backend-Viewer.git
   cd Ataa-Charity-Platform-API-Backend-Viewer
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run locally:
   ```bash
   npm start
   ```
